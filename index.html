学习目标 ​

完成课程后，你应能从空目录交付一个 Python Agent 服务：

  • 用数据模型和运行时校验约束外部输入；
  • 用异步、HTTP、FastAPI 和测试构建后端；
  • 实现 Tool Calling、知识库检索、引用和拒答；
  • 处理超时、重试、幂等、权限和人工确认；
  • 用评测集、trace、成本和延迟判断版本是否回归。

推荐入口 ​

  1. 先做诊断，不要用自评跳过能力节点；
  2. 阅读能力路径，理解主线和可选分支；
  3. 从 Python 后端底座开始；
  4. 完成知识库 Agent 案例；
  5. 再根据目标进入 Agent 应用、后端交付或 LLM 原理课程。
