# 拆包断言核对

> `docs/tutorial/unpack.md` 通篇在声称「这段代码的结果是 xxx」。
> 我把每一条声称写成可执行断言，让 Python 自己判 TRUE/FALSE，
> 不靠我读代码的印象。
>
> 证据：`.walkthrough/evidence/unpack-claims-audit.py`（可重复运行）

## 方法

```python
def check(label, claim, got):
    ok = (claim == got)
    ...
```

教程声称的值写进 `claim`，实际运行结果写进 `got`，两者逐一比对。
凡教程主动标注「❌ 错误」的片段，用 `check_raises` 判定「是否真的抛异常」。

## 结果

**22 条断言：22 PASS / 0 FAIL**（修复后）。

修复前是 **19 PASS / 3 FAIL**，两条真实失败如下。

### 失败 1 & 2：`(a, *rest), b = ([1, 2, 3], 4)` 的结论是错的

教程在**第六节「嵌套中用星号」**和**第七节速查表**两处写道：

```python
(a, *rest), b = ([1, 2, 3], 4)
# a = [1, 2, 3], rest = [2, 3], b = 4     ← 教程声称
```

实测：

```
教程声称: ([1, 2, 3], [2, 3], 4)
实际得到: (1, [2, 3], 4)
```

**为什么教程错了**：外层目标是 `(a, *rest)` 和 `b` 两个。右侧第一个元素
`[1, 2, 3]` 交给 `(a, *rest)`，在这里**再拆一次**：`a` 拿第一个元素 `1`，
`*rest` 收集剩下的 `[2, 3]`。教程把「收到整个 `[1,2,3]`」当成了 `a` 的值，
漏了内层那一次拆包。

这个错误在教程里出现两次，且速查表是学习者最后回去查的地方，
误导成本最高。已在两处改正（D-01）。

### 我自己的断言写松了（不计入教程缺陷）

初版我把「应报错」的判定写成字符串精确匹配，导致 3 条本应 PASS 的
被判 FAIL。改成 `check_raises`（只要真抛异常即 PASS，并记录异常类型与
消息）后这 3 条全部 PASS。记在这里是因为它说明一件事：
**断言写错会比不写断言更危险**——它会给出「教程有问题」的假信号。

## 顺带发现的两处表述不精确

### D-02：错误原因诊断与实际报错不符

教程写：

```python
# ❌ 错误：左侧2层，右侧只有1层
(a, b), c = (1, 2, 3)
```

实测报错：

```
ValueError: too many values to unpack (expected 2)
```

真实原因是**外层**目标数 2 < 右侧元素数 3，报错发生在外层数量比对，
内层 `(a, b)` 根本没被拆到。教程的「左侧2层，右侧只有1层」会让学习者
去数层级，而该看的是每层的**数量**。已改为准确描述。

### D-03：「完整 BNF 范式」名不副实

教程给出：

```text
目标表达式 := 变量 | (目标表达式, 目标表达式, ...)
赋值 := 目标表达式 = 可迭代对象
```

并称之为「完整 BNF 范式」。它至少漏了四类合法目标形式，我逐一实测确认
它们都合法：

| 未覆盖的形式 | 实测 |
|---|---|
| 方括号列表目标 `[a, b] = [1, 2]` | 合法 |
| 属性目标 `obj.x, obj.y = 10, 20` | 合法 |
| 下标目标 `lst[0], lst[1] = 7, 8` | 合法 |
| 星号收集目标 `a, *rest = [1, 2, 3]` | 合法 |

另外教程多处写「左侧有几个 `(...)` 右侧就有几层」，暗示层级由**括号数量**
决定。实测 `a, (b, c) = 1, (2, 3)` 完全合法——括号只是分组符号、可省略，
层级由**目标的结构**决定。已改为「结构对应」。

## 我主动构造的反例（教程没提，但影响我形成正确心智模型）

| 反例 | 实测 | 教我的事 |
|------|------|---------|
| `a, (b, c) = 1, (2, 3)` | 合法，`a=1, b=2, c=3` | 括号可省略，看结构不数括号 |
| `p, q, r = iter([1,2,3])` | 合法 | 右侧只要是可迭代对象，迭代器也行（一次性） |
| `u, v = {1, 2}` | 能拆，但顺序不保证 | 教程说「任意可迭代对象」但没提醒集合无序 |
| `a, *b, c = [1]` | `ValueError: not enough values to unpack (expected at least 2, got 1)` | 星号两侧至少各要一个元素 |
